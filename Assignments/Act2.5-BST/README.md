# Act 2.5 - Árbol Binario de Búsqueda (BST)

Implementación en C++ de un ADT de tipo Árbol Binario de Búsqueda utilizando plantillas (`templates`) y programación orientada a objetos.

## Preguntas de Reflexión

1. **¿Qué aprendiste al implementar los métodos?**
   Aprendí a gestionar estructuras de datos jerárquicas mediante recursividad, así como la lógica detallada para la eliminación de nodos considerando los casos base (sin hijos, con un hijo y con dos hijos).

2. **¿Qué tan útil fue Copilot en esta actividad?**
   Fue muy útil para generar rápidamente la estructura repetitiva de los diferentes tipos de recorridos y la configuración inicial de las clases.

3. **¿Hubo errores que Copilot cometió?**
   En la lógica de reasignación de apuntadores al eliminar nodos con dos hijos, requirió ajustes manuales para asegurar que no se perdieran referencias en el subárbol derecho.

4. **¿Consideras que Copilot te ayuda a aprender o puede matar tu comprensión si se usa mal?**
   Ayuda significativamente a optimizar el tiempo de desarrollo si se analiza cada fragmento de código, pero puede perjudicar la comprensión si se utiliza únicamente para copiar y pegar sin entender el trasfondo algorítmico.

5. **¿Qué harías diferente la próxima vez para aprender más?**
   Diseñar y escribir los diagramas de flujo de los casos de eliminación desde cero antes de apoyarme en herramientas de asistencia de código.
