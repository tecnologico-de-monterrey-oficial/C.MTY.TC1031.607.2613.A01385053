# Evidencia 2 - Actividad Integral de Estructuras de Datos Lineales

Aplicación desarrollada en C++ para el procesamiento, ordenamiento y consulta de registros de red (*logs*) utilizando estructuras de datos lineales basadas en listas doblemente ligadas.

## Instrucciones de Compilación y Ejecución

Para compilar el proyecto mediante la terminal (g++), ejecuta el siguiente comando en la raíz del repositorio:

```bash
g++ -std=c++17 main.cpp -o log_processor
